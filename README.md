&#x20;🌍 GlobalBank Exchange - Gestion des Devises



&#x20;📖 Description

Application web professionnelle de gestion des devises et taux de change pour banque.  

Permet la gestion complète des opérations de change, des utilisateurs et des rapports.



&#x20;🏗️ Architecture Technique



&#x20;Backend

Framework: Flask

Base de données: PostgreSQL / SQLite (dev)

Authentification: JWT



&#x20;Frontend

Framework: React 18

Styling: Tailwind CSS

Graphiques: Recharts

PDF: jsPDF



🚀 Installation et Exécution



Prérequis

\- Python 3.9+

\- Node.js 18+

\- PostgreSQL (optionnel)



Installation Backend

bash

cd backend

python -m venv venv

source venv/bin/activate  # Ou venv\\Scripts\\activate sur Windows

pip install -r requirements.txt

python app.py
